# Démarrage du projet

## Lancer l'API backend

```bash
cd api
python server.py
```

## Lancer le front-end (nécessite Node.js et live-server ou équivalent)

```bash
cd frontend
npx live-server public
```

Ouvrez ensuite le navigateur à l'adresse indiquée par live-server (par défaut http://127.0.0.1:8080/).

---

Le pipeline ETL reste inchangé et s'exécute depuis la racine du projet avec :

```bash
python main.py
```
